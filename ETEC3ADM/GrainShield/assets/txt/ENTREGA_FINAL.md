## 🎨 CUSTOMIZAÇÕES FÁCEIS

### **Trocar Cores**
Edite `style.css` linhas 6-20:
```css
--cor-primaria: #2B6F3D;        /* Verde agronegócio */
--cor-secundaria: #185FA5;      /* Azul profissional */
--cor-destaque: #F2A623;        /* Ouro/Amarelo */
```

### **Mudar Tipografia**
Edite `style.css` linhas 21-23:
```css
--fonte-display: 'Playfair Display', serif;
--fonte-corpo: 'Lato', sans-serif;
```

### **Atualizar Textos**
Abra cada `.html` e procure pelo texto a modificar

### **Adicionar Imagens Reais**
Substitua `https://via.placeholder.com/...` pelos caminhos reais
